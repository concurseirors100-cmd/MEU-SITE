# Versão antiga (guardada por segurança)

`questia-original.html` é o QuestIA como era antes da reorganização em arquivos:
um único HTML com CSS e JavaScript embutidos, código idêntico ao original.

Foram retirados apenas os dados que o navegador gravou junto ao "Salvar página"
(questões, comentários, resumos e estatísticas que estavam na tela) — o repositório
é público. Seus dados de estudo continuam no navegador, intactos.

Para usar esta versão, basta abrir o arquivo no navegador.
